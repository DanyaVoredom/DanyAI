# Changelog

## 0.3.1

- инференс: слияние qkv и gate/up в один матмул на слой
- инференс: предвыделенный KV-кэш вместо concatenate на каждом токене
- инференс: скользящее окно контекста вместо пересчёта всего префилла после 96 токенов
- инференс: инкрементальный UTF-8 декодер, logits только для последней позиции на префилле
- инференс: статическая causal-маска, in-place softmax, hoisted RoPE-таблицы
- скорость на ПК: 171.6 -> 218.4 tok/s на модели 3.8M, 32 токена с длинным промптом 0.95 -> 0.18 с
- скорость на телефоне: 29.7 -> 39.5 tok/s на модели 3.8M
- server: поддержка stop, usage с числом токенов, ограничение max_tokens
- llama.cpp на телефоне: сборка с GGML_NATIVE, сервис danyai-llama на 8081, модель Q4_K_M
- litellm-шлюз на 4000, модели danyai-qwen (llama.cpp) и danyai-nano (numpy-сервер)
- Android: phantom process killer и doze отключены через adb, сервисы переживают сон экрана
- тесты: 15 passed, добавлены проверки слияния весов и скользящего кэша
